# AITeam v0.7.0

Wires up part of the `config-templates` design that had been documented but never actually read by the running app.

## Changes

- Added `RuntimeConfigService` (`AITeam.Core`), which loads:
  - `data/settings.json` (falls back to legacy `config/settings.json`) for `workflow.max_repair_rounds`.
  - `data/agents.json` (falls back to legacy `config/agents.json`) for per-provider `command` overrides (`agents.codex.command`, `agents.claude.command`, `agents.antigravity.command`).
  - Any missing file, missing field, or malformed JSON silently falls back to the same defaults the app already hard-coded (`max_repair_rounds = 3`, commands `codex`/`claude`/`agy`) — an optional config file can never break startup or a running task.
- `ChangeTaskService`'s repair loop now uses the configured `max_repair_rounds` instead of a hard-coded `3` (the loop bound and the "N 輪修正後仍未通過" message both use the configured value).
- `InquiryService`, `ChangeTaskService`, and `ProviderHealthService` now resolve the actual CLI executable name for Codex/Claude/Antigravity through `AgentsConfig` instead of hard-coded `"codex"`/`"claude"`/`"agy"` literals, so a machine that installs one of these CLIs under a different command name can point AITeam at it without a source change.
- Added `tests/AITeam.Core.Tests/RuntimeConfigServiceTests.cs` covering: reading declared values, defaulting on missing/invalid fields, `data/` taking priority over legacy `config/`, and falling back to defaults on malformed JSON.

## Not yet wired

`config-templates/settings.example.json`'s `paths` section (`worktrees_root`, `tasks_root`, `logs_root`, `profiles_root`) and `agents.json`'s per-agent `enabled` flag are still not read by the app — changing where AITeam stores its runtime data, or disabling a provider at the machine-config level rather than per-session in the GUI, both need more invasive changes (touching `RuntimeRootResolver`, the worktree/task path construction, and the provider candidate list in `MainWindow`) that are deferred to keep this change reviewable on its own.

## Still next
