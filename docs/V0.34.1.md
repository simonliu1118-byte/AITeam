# V0.34.1

## 審查的 AI 現在看得到新建立的檔案

修改任務裡，實作的 AI 新建立的檔案（例如新的程式檔、新的說明文件）還沒被 Git 追蹤，
所以之前交給**挑戰、最終審查、修正**這幾步看的「改了什麼」只包含修改既有檔案的部分。
新檔案的內容等於沒人審查。

這版在整理差異之前，先把新檔案標記成「打算加入」。這樣審查的 AI 就看得到完整內容，
「實作完成，等你確認」那個視窗的變更摘要也會列出新檔案。

- `.gitignore` 排除的檔案（例如建置產物、執行紀錄）跟以前一樣不會被帶進來。
- 行尾空白檢查一樣只看修改既有檔案，新檔案不會因為這項檢查被擋下來（跟以前相同）。
- ChatGPT 人工接續的流程本來就看得到新檔案，沒有變動。
