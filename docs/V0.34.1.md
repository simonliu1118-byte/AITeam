# V0.34.1

## 審查的 AI 現在看得到新建立的檔案

修改任務裡，實作的 AI 新建立的檔案（例如新的程式檔、新的說明文件）還沒被 Git 追蹤，
所以之前交給**挑戰、最終審查、修正**這幾步看的「改了什麼」只包含修改既有檔案的部分。
新檔案的內容等於沒人審查。

這版在整理差異之前，先把新檔案標記成「打算加入」。這樣審查的 AI 就看得到完整內容，
「實作完成，等你確認」那個視窗的變更摘要也會列出新檔案。

- `.gitignore` 排除的檔案（例如建置產物、執行紀錄）跟以前一樣不會被帶進來。
- 行尾空白檢查一樣只看修改既有檔案，新檔案不會因為這項檢查被擋下來（跟以前相同）。
- ChatGPT 人工接續的流程本來就看得到新檔案，沒有變動。

## 下載下來解壓縮一次，就是 AITeam 資料夾

以前下載測試包要解壓縮兩次（外面一層 zip、裡面還有一層 zip），最後還得到一個
`AITeam-v0.34.0-win-x64` 這種帶一串版號的資料夾。現在改成：

- **測試包（Actions Artifact）**：下載的檔名是 `AITeam-V0.34.1`（返修時是 `AITeam-V0.34.1-Build1`），
  解壓縮一次就是 `AITeam` 資料夾，裡面是 `AITeam.exe` 和 `使用說明.txt`。
- **正式版（Release）**：下載的檔名是 `AITeam-V0.34.1.zip`，裡面一樣是一層 `AITeam` 資料夾。
  自動更新也改成認這個名稱。

版號格式照共通規則：使用者看到的是 `VX.Y.Z`，有返修時加 `Build N`；Git tag 維持 `vX.Y.Z`。

### 已經有 D:\AITeam 的電腦

原本 D 槽的東西**都不用搬**。解壓縮時把目的地選成 `D:\`，`AITeam` 資料夾就會跟原本的
`D:\AITeam` 合在一起，只覆蓋 `AITeam.exe`。之後 D:\AITeam 本身就是可攜的家，整個資料夾
可以搬到別台電腦。

就算把新的 AITeam 資料夾放在別的地方，只要那個資料夾裡還沒有 `data`，程式也會自動沿用
D:\AITeam 的資料。
