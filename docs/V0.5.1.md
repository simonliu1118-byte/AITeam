# AITeam v0.5.1

Patch release. No new features; fixes bugs found while reviewing the v0.5.0 change pipeline and removes stale/duplicate code.

## Fixes

- The change-task pipeline now correctly reports `RequestIntent.Change` (with the full `ChangeTaskResult`) instead of always reporting `RequestIntent.Inquiry` once a modification pipeline finished. The UI now shows "修改完成 · {version}（{tag}）" for a completed change instead of the old inquiry-completed / not-yet-implemented text.
- `VerifyWorkingTreeAsync` now runs `git diff HEAD --check` instead of `git diff --check`, so whitespace/conflict-marker checks also cover changes the implementer AI has already `git add`ed.
- `GetRemoteDefaultBranchAsync` now falls back to the project's own registered `DefaultBranch` before guessing `main`/`master`, used whenever `origin/HEAD` cannot be resolved.

## Cleanup

- Removed `MainForm.cs`, an unused v0.2 alpha UI implementation left over from before `MainWindow` became the real entry point (`Program.cs` never referenced it).
- Consolidated the four duplicate `FriendlyProvider`/`FriendlyState` switch statements into `ProviderIdExtensions.ToFriendlyName()` / `ProviderHealthStateExtensions.ToFriendlyName()` in `Models.cs`.
- Updated `README.md` to describe the EXE as the primary implementation (it had still described `v0.2.0-alpha.1`-era side-by-side status).

## Still next
