# V0.24.2

## 1. AI 自己踩到的錯誤不再顯示在「現在在做什麼」

Codex 在 Windows 上是用 PowerShell 執行它的工具。找不到某個檔案時，PowerShell 會吐出
一整串錯誤：

```
+ FullyQualifiedErrorId : PathNotFound,Microsoft.PowerShell.Commands.GetContentCommand
```

那一行被原封不動顯示在狀態列的「現在在做什麼」，看起來像整件事失敗了——
但那只是 Codex 試了一個路徑、沒找到、換個方法再試，**它後來照樣正常發言**。

`ProviderActivity` 現在會濾掉這類噪音：`+ ` 開頭的 PowerShell 錯誤脈絡行、
`At line:`、`FullyQualifiedErrorId`、`CategoryInfo`、`Microsoft.PowerShell.Commands`，
以及整行只有 `~~~~` 的指示線。真正的進度訊息不受影響。

## 2. 「現在輪到誰」移到逐字稿裡

以前「Gemini 正在發言…」在畫面最下方另外一條列，跟內容分開，不容易注意到。

現在輪到誰，**逐字稿裡就直接出現那個人的標題**：

```
第 1 輪 · Gemini / Antigravity
正在發言…
```

等它講完，「正在發言…」那一段會被真正的內容整段換掉（含分隔線）。
失敗或被跳過時也一樣就地換成結果，不再另外補一行系統訊息。

為此 `LinkFoldingLog` 新增 `Mark()` / `TruncateTo()`：記住一個位置，之後把從那裡
開始的內容整段換掉。

## 3. 底下那條列拿掉，按鈕併進同一排

「跳過這家 / 停止這一輪」原本在那條列上，現在移到最下面那排按鈕，
跟「結束會議 / 直接定案 / 請 AI 收斂結論 / 繼續下一輪」共用同一個位置：

- **有人在發言時**：只出現「跳過這家」「停止這一輪」
- **輪到使用者時**：只出現另外四顆

同一時間只有一組用得上，所以用顯示／隱藏切換，畫面少一個區塊。

## 4. 不再多做一個計時器

上方狀態列本來就有「第 1 輪 · Gemini / Antigravity 發言中 00:55」的計時，
逐字稿裡的標題就不再重複顯示時間。軟逾時到了也只是在狀態列尾巴加一句
「⚠ 想很久了，可按『跳過這家』」，不另外跳東西。

## 關於開啟程式時閃一下 PowerShell

**這不是 AITeam 自己開的視窗。** AITeam 啟動每一個 CLI 時都已經指定「不要建立視窗」
（`CreateNoWindow`），我們這一層是乾淨的。

閃出來的是**孫程序**：Codex 在 Windows 上用 PowerShell 執行它自己的工具
（本次的錯誤訊息 `Microsoft.PowerShell.Commands.GetContentCommand` 就是證據），
而程式啟動時會自動做一次三家 AI 的健康檢查，所以一開程式就看得到。
孫程序要不要開視窗由 Codex 決定，父程序這一層擋不到。

唯一已知的手法是讓 AITeam 自己配置一個隱藏的主控台並讓子孫程序共用它，
但那個做法本身有機會反而先閃一下，而且我無法在這裡實測，所以**沒有直接改**——
要不要試，等使用者決定。
