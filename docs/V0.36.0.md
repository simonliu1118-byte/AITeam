# V0.36.0

## AI 出狀況時，AITeam 自己處理，不用開 PowerShell

### 登入、更新按鈕
AI 狀態卡片上，需要動手的時候會多一顆按鈕：

| 狀態 | 按鈕 | AITeam 會做什麼 |
|---|---|---|
| 需登入（GPT / Codex、Claude） | 登入 | 開一個視窗替你執行登入，瀏覽器跳出來後照畫面登入即可 |
| 錯誤（GPT / Codex、Claude） | 更新 | 開一個視窗把這個 AI 工具更新到最新版 |

視窗跑完會停著讓你看結果，按任意鍵關閉後，AITeam 會自動重新檢查三個 AI。
Antigravity 沒有可以代勞的指令，需登入時卡片會提示到 Antigravity 程式裡重新登入。

### GPT / Codex 的模型自動挑選
Codex 的預設模型你的帳號不能用時（例如「not supported when using Codex with a ChatGPT account」），
健康檢查會從 Codex 內建的模型清單依序試，找到能用的就記下來（`data\preferences.json`），
之後實作、審查、會議叫 Codex 都指定這個模型。執行紀錄會寫出改用了哪個模型。
額度用完、需要登入這種跟模型無關的問題不會觸發換模型。

### 匯入專案時登入 GitHub
「從 GitHub 匯入」發現這台電腦的 GitHub 還沒登入時，視窗下方會出現「登入 GitHub」，
按了開視窗登入，完成後自動列出你的 Repo。

## AI 狀態判斷更準確

- **Claude 登入過期被誤判成「超過限額」**：Claude 回報的原始資料裡有一些跟限額有關的欄位名稱，
  以前會被當成限額訊息。現在挑得出錯誤訊息時，只依訊息本身判斷；「Failed to authenticate」
  「OAuth session expired」這類訊息會正確顯示成「需要重新登入」。
- **Antigravity 的錯誤訊息**：只留下給人看的那一句（例如「Individual quota reached. Resets in 97h11m55s.」），
  後面那段給程式看的資料不再塞進執行紀錄；完整內容仍在 `logs\health-antigravity.log`。
- 紀錄裡真的需要截短時，不再用「…」，改寫「（後面省略）」，完整內容都在 logs 資料夾。
