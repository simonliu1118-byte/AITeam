# AITeam v0.5.0

This release activates the first guarded modification pipeline in the EXE.

## Change workflow

For requests classified as changes, AITeam now runs:

1. Gemini/Antigravity preferred Scout + evidence
2. GPT/Codex preferred Plan Gate + risk/version classification
3. Claude preferred implementation + tests
4. deterministic Git verification (`git diff --check`, changed-worktree check)
5. independent Gemini-preferred Challenge
6. GPT-preferred Final Review
7. up to 3 repair rounds when Final Review requests repair
8. version bump
9. commit + tag
10. atomic push of default branch + tag to GitHub

Role fallbacks use the currently online providers. A modification requires at least two online providers so implementation and independent review are not silently collapsed into one AI.

## Safety

- all edits happen in `D:\AITeam\worktrees\...`
- the managed repository must be clean and safely synchronized first
- if GitHub default branch changes while the task is running, formalization stops
- push uses `git push --atomic` so branch/tag do not partially publish
- failed / non-formalized tasks keep their worktree for inspection
- successful tasks remove their temporary worktree
- no force push
- existing tags are never overwritten
- v0.5.0 only auto-bumps simple `X.Y.Z` version files; prerelease/custom version formats stop before formalization instead of being guessed

## Version bump policy

Plan Gate returns PATCH / MINOR / MAJOR according to the project policy. PATCH is the conservative fallback when the planner does not return a valid bump.
