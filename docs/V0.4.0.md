# AITeam v0.4.0

## UI corrections

- Card borders are drawn further inside the control to avoid right-edge clipping.
- Provider status lamps are painted directly on the card; the old square background artifact is removed.
- `AI 狀態` and `執行進度 / 結果` use matched vertical spacing.
- `管理專案` height follows the adjacent project combo box.
- Project summary now labels `Repo` and `本機位置` explicitly.
- New AITeam teamwork icon is embedded in the executable so Explorer/desktop shortcuts can use the EXE icon.

## Project Manager

- Restores a persistent registered-project list.
- `新增專案` enters explicit add mode and no longer replaces the selected project.
- Editing occurs only after selecting an existing registered project.
- Duplicate project names are rejected rather than silently replacing another entry.
- Save/remove refresh the list immediately.

## Inquiry engine

`送出` is now functional for read-only inquiries:

1. A detached temporary Git worktree is created under AITeam runtime storage.
2. An available AI inspects only that isolated copy.
3. The AI classifies the request as `INQUIRY` or `CHANGE`.
4. Inquiry requests return a real answer in the result pane.
5. Change requests are detected but are not implemented in v0.4.0; the full three-AI modification pipeline is intentionally deferred until its review/repair/versioning path is complete.
6. The temporary worktree is removed after the run.

Provider preference remains GPT / Codex -> Gemini / Antigravity -> Claude among providers currently marked online and enabled for the session.
