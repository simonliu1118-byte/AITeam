# AITeam v0.16.1

AI 失敗時，把原因寫進畫面。

## 問題

實測時 log 出現這兩行：

```
[20:06:30] GPT / Codex 正在讀取專案並判斷需求...
[20:06:31] GPT / Codex 本次失敗，嘗試下一個 AI。
```

使用者問「GPT 失敗的原因是什麼？」——**查不到**。

原因不是沒抓到，是抓到了卻被丟掉：失敗訊息只被收進一個 `failures` 清單，而那個清單
只有在「所有 AI 都失敗」時才會顯示出來。這次 Gemini 接手成功，於是 GPT 的錯誤訊息
再也沒有任何地方看得到，連歷史紀錄裡也沒有。

## 改了什麼

- 失敗當下就把原因寫進 log：`「GPT / Codex 本次失敗，改試下一個 AI。原因：…」`。
  訊息會壓成一行並截斷（上限 300 字），不會一則 log 洗掉整個畫面。
- CLI 失敗訊息補上結束碼。有些 CLI 失敗是靜默的（結束碼非 0 但沒有任何輸出），
  原本會顯示成沒有內容的「未知錯誤」；現在至少看得出「它確實跑起來又失敗了」。

## 這次還是查不出 GPT 為什麼失敗

這一版是讓**下次**查得到。這次的原因已經隨著當時的執行結束而消失了，無從回溯。
從時間上只能看出它在 1 秒內就失敗，屬於「程序層級的立即失敗」（例如 CLI 直接拒絕），
不是模型跑太久逾時——但確切原因需要下次重現才會顯示出來。
