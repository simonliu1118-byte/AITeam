# V0.26.0

## Claude 也看得到即時進度了

三家 AI 裡只有 Claude 在工作時畫面上完全沒有動靜——因為它是用
`--output-format text` 跑的，那個模式**整個過程都不輸出任何東西**，只有最後才吐出答案。

改成 `--output-format stream-json --verbose`。這個模式每一行是一個事件：

| 事件 | 畫面上顯示 |
|---|---|
| `system` | 啟動中… |
| `assistant` 裡有 `tool_use` | 使用工具：Read |
| `assistant` 裡是文字 | 正在回答… |
| `user`（工具結果） | 讀取工具結果… |
| `result` | 完成 |

### 為什麼要另外寫一個解析器

新增 `ClaudeStream`：

- **最終答案**改成從 `result` 事件取，而不是整段 stdout。
- **被中途砍掉時**（逾時、使用者按停止）沒有 `result` 事件，就把 `assistant` 說過的
  文字接起來——至少拿得回它已經講出來的部分，而不是整段丟掉。
- **`is_error` 判斷**：Claude 超過限額時會以結束代碼 0 結束，只在 `result` 事件裡標
  `is_error`。只看結束代碼會把失敗當成成功。

活動描述也要另外處理：Claude 的**工具名稱包在 `message.content[]` 裡面的 `tool_use` 區塊**，
跟另外兩家的格式完全不同，通用的找法抓不到。

### 如果你的 CLI 版本不吃這些參數

**會自動退回原本的純文字格式**。判斷方式是看失敗訊息像不像「不認得這個參數」
（`unknown option` / `Usage:` 之類）；如果是別的原因失敗，就照實報錯、不會亂退。

退回之後功能照常，只是看不到即時進度——也就是回到這一版之前的行為。
