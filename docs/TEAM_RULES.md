# AITeam Team Rules — Legacy Index

AITeam 的永久產品規則已集中至 repository 根目錄：

- `REPOSITORY_RULES.md` — 三個 repository 共通規則母本。
- `REPO_POLICY.md` — AITeam repository-specific policy。
- `PROJECT_RULES.md` — AITeam 產品本身唯一 project-specific rules。

本檔保留名稱僅為避免舊文件、舊對話或工具連結失效，**不再是永久規則來源**。

需要修改 AITeam pipeline、AI 角色、worktree、版本、Git、Release 或 provider fallback 規則時，必須依 governance 流程修改上述正式規則，不得在本檔新增另一套規則。
