# V0.24.1

實機回報的四件事。

## 1. 會議開始後，議題與參與者改成置頂顯示

以前議題與參與者是逐字稿的第一、二則訊息——講幾輪就被捲走，回頭要找還得往上滾。

會議一開始，上方的設定表單就整個換成**置頂摘要**：

- 議題（粗體、大字）
- 參與者、模式、規模（含字數）、專案、**已呼叫幾次**
- 右上角保留一個**規模下拉**，中途要調整不必回去找

設定表單在會議開始後就不再出現——那些選項本來就不該中途被改。

## 2. 每則發言後面加一條分隔線

以前一則接一則，看不出「這個人講完了」。現在每則發言變成：

```
第 1 輪 · Claude            ← 粗體、強調色，一眼掃得到是誰
（內容）
────────────────────────    ← 淡灰分隔線，代表講完了
```

## 3. 主畫面「停止」與「送出」沒對齊

兩顆按鈕尺寸不同（84×42 vs 116×42），而且「送出」沿用預設的 3px 邊界、又沒有指定
`Anchor`，所以會比旁邊差半格。改成兩顆都是 108×40、邊界一致、都用 `Anchor = Left`
垂直置中。

## 4. 「待命」徽章緊跟在「目前任務」後面

先前它被彈性欄推到最右邊，跟「歷史任務」按鈕擠在一起。欄位順序改成
**標題｜徽章｜彈性空白｜歷史任務**，徽章與標題之間留 12px。

## 順帶：Gemini 的軟逾時放寬到 5 分鐘

Gemini / Antigravity 光是啟動就比另外兩家慢很多（健康檢查 28 秒，另外兩家 6～8 秒）。
用同一個 3 分鐘門檻會一直跳「可能卡住了」，讓人以為它壞掉，其實只是它比較慢。
所以它的軟逾時改成 5 分鐘，其他兩家維持 3 分鐘。硬逾時（15 分鐘）不變。

另外會議狀態列加上 `AutoEllipsis`，並把「已呼叫次數／規模」移到置頂摘要——
先前那一行太長會被切掉，右邊只看得到半個「規」字。
