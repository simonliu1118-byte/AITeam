# V0.35.0

## 從 GitHub 匯入專案

換電腦或從頭開始時，不用再一個一個手動新增專案。「專案管理」右上角多了「**從 GitHub 匯入**」：

1. **勾選 Repo**：列出你的 GitHub 帳號看得到的所有 Repo（自己的、協作的、組織的；已封存的不列），
   私人 Repo 會標「（私人）」，已經有專案登錄的 Repo 會標出登錄了幾個。
2. **找出專案**：AITeam 把勾選的 Repo 下載到本機，找出裡面有 `VERSION` 檔的資料夾，
   每一個都是一個專案（共通規則：每個可發行專案的根目錄都有 VERSION）。
   整個 Repo 都沒有 VERSION 的話，就把整個 Repo 當成一個專案。
3. **勾選專案、匯入**：預設全勾，不要的取消就好。已經登錄過的專案不會再列出來。

- 專案名稱用資料夾名稱（整個 Repo 就用 Repo 名稱）；名稱重複時後面加上 Repo 名稱區分。
- 專案說明先帶入那個資料夾 README 的第一段正文，之後可以在專案管理裡修改。
- 需要這台電腦的 GitHub CLI（gh）已經登入；沒登入時會直接告訴你。
- 某個 Repo 下載失敗不會影響其他 Repo，失敗的會列在視窗下方。

## AI 狀態檢查失敗時，看得懂原因

以前檢查失敗時，執行紀錄裡是一大串 CLI 的原始 JSON，還被截斷，看不出真正的原因。現在：

- 從 JSON 裡挑出真正的錯誤訊息，例如「This model requires a newer version of Codex」，整句顯示，不截斷。
- CLI 的完整輸出另外存在 `logs\health-codex.log`（Claude、Antigravity 各一個檔），紀錄裡會寫出檔案位置。
