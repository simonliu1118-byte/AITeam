# AITeam v0.7.1

Patch release. First implemented step of `docs/PIPELINE_REDESIGN.md`.

## Fix

- `InquiryService.RunAsync` now calls `SafeSyncAsync` (same safety checks as the
  change-task pipeline: local repo must be clean, must not be ahead of GitHub,
  fast-forwards if behind) before creating the read-only inquiry worktree.
  Previously, an inquiry answered questions based on whatever the local clone's
  `HEAD` happened to be, which could be stale if no change task had run recently
  while GitHub moved on. Inquiry and Change now share the same "sync before doing
  anything" guarantee.

See `docs/PIPELINE_REDESIGN.md` §一 for the full rationale and the remaining items
in this redesign.
