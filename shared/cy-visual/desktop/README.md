## Governance boundary

This package is not a fourth governance layer. A repository or project adopts it through its normal three-layer governance chain (`REPOSITORY_RULES.md` → `REPO_POLICY.md` → `PROJECT_RULES.md`). Once adopted, relevant UI / visual work must use this AITeam package as the shared canonical source unless the project has an explicit permitted exception.

Family icon production assets remain under `../icon-family/`.
