# CY Icon Family Changelog

## 0.2.0 — 2026-09-24

Documentation consolidation before production icon work.

- Consolidated the former family reference and AI creation brief into `ICON_FAMILY.md`.
- Removed the standalone version file; family history is tracked here instead.
- Clarified that AITeam keeps the canonical family documents while downstream app repositories receive only their approved app-specific production assets.
- Clarified that the historical INV live-area measurements are reference only, not the future square-family geometry target.
- Defined the next production step as creating `master/CY_ICON_MASTER.svg` and deriving the full INV / ACC / ENV / Auto / WTM / CVT / CAL family from it.

## 0.1.0 — 2026-09-23

Initial shared canonical package.

- Established AITeam as the upstream source for CY cross-repository icon-family references.
- Adopted the new square-family direction.
- Defined shared frame/body geometry, identifier zone, app-specific motif zone, color strategy, optical consistency, and small-size production principles.
- Defined short uppercase identifiers as the default and `Auto` as the approved readability exception.
- Clarified that the two horizontal lines are specific to INV.
- Recorded the current family scope across CYapps and CYapps_pvt.
- Explicitly excluded DriveDownloader from the CY App Icon Family.
